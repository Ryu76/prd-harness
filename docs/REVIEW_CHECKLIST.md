# Codex PRD 검토 체크리스트

## 요구사항

- [ ] 문제와 목표가 한 문장 이상으로 구분돼 있다.
- [ ] 완료 조건이 관찰 가능한 결과로 작성돼 있다.
- [ ] 기대하지 않는 변경이 적혀 있다.

## 범위와 안전

- [ ] 수정 가능 파일 또는 모듈이 명시돼 있다.
- [ ] 수정 금지 대상이 명시돼 있다.
- [ ] API 키, 인증 정보, DB 스키마, 배포 설정 변경이 포함되지 않는다.
- [ ] `allow_commit`, `allow_push`, `allow_db_change`, `allow_network`는 모두 `false`다.
- [ ] `risk`가 `low`인지 확인했다. `medium`·`high`는 자동 실행 대상으로 보내지 않는다.

## 검증

- [ ] 실행할 테스트 명령이 있다.
- [ ] 수동 확인 항목이 있다.
- [ ] 실패 시 되돌리는 방법이 있다.
- [ ] 변경 후 사람이 diff와 테스트 로그를 검토한다.

## 승인

- [ ] `status`를 `approved`로 바꿀 근거가 있다.
- [ ] 현재 저장소의 기존 변경 사항을 별도로 확인했다.
- [ ] PRD ID가 이전 작업과 중복되지 않는다.
